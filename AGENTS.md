# Project rules

- Main app file: pension-simulator.html
- Do not edit API files unless explicitly requested.
- Preserve existing Supabase save/load behavior.
- Prefer minimal diffs.
- Do not refactor unrelated sections.
- Mobile breakpoint is 768px.
- realEstatePlan is the canonical real-estate state.

- Run a JavaScript syntax check after changes when possible.
- Before editing, inspect the relevant DOM, CSS, and JavaScript.
- After editing, report only:
  1. Changed files
  2. Core changes in three lines
  3. Test results
